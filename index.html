How to get the token on iPhone
  1. Tap Copy bookmarklet.
  2. In Safari, bookmark any page (Share, Add Bookmark), then Bookmarks, Edit, open that bookmark and replace its address with the copied text; name it "LR token".
  3. Open languagereactor.com in Safari and log in.
  4. Open Bookmarks and tap "LR token": a box shows your email; tap Copy for LR Reader.
  5. Back here: Paste Language Reactor login, then Save.
The bookmarklet only asks Language Reactor for your own token, using the login already in Safari.

Reading

Language Reactor counts very common words as known without saving them. Words you marked still win.

Voice

Sync

Books, positions, bookmarks, words, stats, summaries and settings (not API keys) sync on start, when you leave the app and every few minutes in the library.

Backup

On iPhone: Save backup, then Save to Files > iCloud Drive (the same name replaces the old one). Books, positions, bookmarks, word lists, summaries, stats, settings and pending marks. Translations are not included (they are fetched again).

Storage and offline

Removes cached translations and word lookups (they are fetched again when needed). Summaries, saved words and pending marks stay.
